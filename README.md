# 🚀 AWS VPC Peering Project

## 📖 Project Overview

This project demonstrates how to establish secure communication between two Amazon Virtual Private Clouds (VPCs) using **VPC Peering**.

The project includes:
- Creating two VPCs (Requester & Accepter)
- Creating Public Subnets
- Configuring Route Tables
- Attaching Internet Gateways
- Creating a VPC Peering Connection
- Launching EC2 Instances
- Verifying connectivity using Private IP addresses
